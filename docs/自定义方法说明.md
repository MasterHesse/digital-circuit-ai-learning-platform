# 自定义方法说明文档（入参/输出/行为）

## KnowledgePointRepository.java

### findPrereqChain

- 方法签名：
  ```java
  List<PrereqDto> findPrereqChain(@Param("kpId") String kpId, @Param("depth") Integer depth);
  ```
- 入参：
  - kpId：起点知识点 ID
  - depth：最大展开深度（1~3）
- 输出：`List<PrereqDto>`，每项含前置知识点信息及相对起点的最短层级
- 行为说明：
  - 递归查找 1~3 层前置知识点，合并去重，返回最短路径层级
  - 排序：`ORDER BY depth ASC, kpId ASC`
  - 建议课程数据保持 DAG 结构

## KnowledgePointController.java

### getById

- 方法签名：
  ```java
  @GetMapping("/{kpId}")
  public ResponseEntity<KnowledgePoint> getById(@PathVariable String kpId)
  ```
- 入参：kpId（路径参数）
- 输出：200 返回 KnowledgePoint，404 不存在
- 依赖：`repo.findById(kpId)`

### prereqs

- 方法签名：
  ```java
  @GetMapping("/{kpId}/prereqs")
  public ResponseEntity<List<PrereqDto>> prereqs(
      @PathVariable String kpId,
      @RequestParam(defaultValue = "2") @Min(1) @Max(3) Integer depth
  )
  ```
- 入参：kpId（路径参数），depth（查询参数，默认2，范围1~3）
- 输出：200 返回 List<PrereqDto>，404 kpId 不存在，400 depth 不合法
- 依赖：`repo.existsById(kpId)`、`repo.findPrereqChain(kpId, depth)`

## CircuitArchiveService.java

### create

- 方法签名：
  ```java
  public CircuitResponse create(CircuitSaveRequest req)
  ```
- 入参：CircuitSaveRequest（含 name, circuit）
- 输出：CircuitResponse
- 行为说明：
  - 构建实体，序列化 circuit 存库
  - repo.save 持久化，自动生成 id/时间戳
  - toResponse 反序列化并返回

### get

- 方法签名：
  ```java
  public CircuitResponse get(UUID id)
  ```
- 入参：id（UUID）
- 输出：CircuitResponse
- 行为说明：
  - repo.findById 查询
  - 不存在抛 404
  - 存在则 toResponse 组装返回

### toResponse（私有方法）

- 方法签名：
  ```java
  private CircuitResponse toResponse(CircuitArchiveEntity e)
  ```
- 入参：CircuitArchiveEntity
- 输出：CircuitResponse
- 行为说明：
  - 反序列化 circuitJson
  - 组装并返回 CircuitResponse
  - 解析失败抛 500
